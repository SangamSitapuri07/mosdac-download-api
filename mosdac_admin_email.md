## ✉️ Mail Body — Option C (agar account approved hai par API 401/error de rahi hai)

> **Subject:** Data Download API login error (401) despite approved account — `<your_username>`

```
Respected Sir/Madam,

My MOSDAC account (username: <your_username>) is registered and as per my understanding
approved. However, when I run the MOSDAC Data Download API (mdapi.py) with my credentials,
the token endpoint returns HTTP 401.

Details:
  - Endpoint : POST https://mosdac.gov.in/download_api/gettoken
  - Response : {"error": "Invalid Username/Password. After 3 Incorrect Attempts, your
                Account will be Locked for 1 Hour."}
  - Script   : mdapi.py (downloaded from https://www.mosdac.gov.in/software/mdapi.zip)
  - config.json search_parameters : datasetId = <datasetId>, startTime/endTime = <dates>
  - Date & time of attempt (IST)  : <DD-MM-YYYY HH:MM>

I have verified that the same credentials work / do not work on the web portal login.
I have attached the error log generated by the script (generate_error_logs: true).

Kindly confirm whether my account is approved for API-based download, and if any
separate permission/whitelisting is required for the download_api endpoint.

Regards,
<Your Name> | <Organisation> | <Mobile> | <Email>
```

## ✅ Bhejne se pehle checklist

- [ ] Subject me apna **MOSDAC username** zaroor likho (admin ko account dhoondhne me aasani hoti hai)
- [ ] Registered email ID wahi likho jo signup me di thi
- [ ] Purpose 2–3 lines me clear likho — vague purpose pe approval late hota hai
- [ ] datasetId aur date range likh do (catalog: https://www.mosdac.gov.in/catalog-app/satellite)
- [ ] **Password mail me kabhi mat likho** ❌
- [ ] Ek hi baar mail bhejo, baar-baar follow-up na karo; reply ka 2–3 working days wait karo
- [ ] Follow-up karte waqt **same thread me reply** karo (naya mail mat bhejo)
